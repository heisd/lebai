# lebai

乐白 LM3 机械臂 ROS 2 Humble 工作空间，包含 SDK、运动学示例、视觉抓取与 Gazebo 仿真。

## 内容导航

- [src/README.md](./src/README.md)：环境、编译与功能总览
- [src/lebai-ros-sdk-humble-dev/README.md](./src/lebai-ros-sdk-humble-dev/README.md)：SDK 说明
- [src/grab_demo](./src/grab_demo)：视觉抓取
- [src/arm_demo](./src/arm_demo)：运动学示例
- [src/lebai_gazebo](./src/lebai_gazebo)：仿真
- [frame.md](./frame.md)：坐标系笔记
- [serivce.md](./serivce.md)：服务相关笔记

## 开始使用

从 [源码工作空间指南](./src/README.md) 选择仿真或实际机械臂流程。`src/` 是源码目录，编译在本仓库根目录执行；视觉方案所需的相机、模型和运行库见对应子项目文档。
